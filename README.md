# Aira Design Studio

Aira is a responsive, browser-based AI design studio concept. Describe an idea, choose a format and style, and generate a design card in the gallery. Browse inspiration by category, save favorites, and download designs as SVG.

## Run locally

Open `index.html` in any modern browser. No build tools or dependencies are required. The Google Fonts connection is optional; the page falls back to system fonts if unavailable.

> Design generation is currently a front-end demo: it creates a visual concept card from your prompt. Connect an image-generation API to the form handler in `index.html` to generate production artwork.
